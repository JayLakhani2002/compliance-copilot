## Open questions for the planner
1. **Python 3.12 not installed locally** — `uv sync` silently used 3.14.6 instead. Fine while there's no runtime code, but once a dependency needs a specific interpreter ceiling (e.g. a library not yet on 3.14), we may hit friction. Suggest either running `uv python install 3.12` and adding `.python-version` pinning 3.12 exactly, or explicitly deciding "we track latest CPython, not exactly 3.12" and updating CLAUDE.md's default line accordingly.
2. **Public vs private repo** — left the `gh repo create` command with `--private` as the default; Jay should override if the portfolio goal (recruiter-visible) argues for public from day one.
3. **hatchling as build backend** — not explicitly specified in the task; chose it as uv's own default for src-layout packages. No ADR written for this (intentionally trivial/reversible), but flagging in case the planner wants an ADR for build-backend choice anyway.
