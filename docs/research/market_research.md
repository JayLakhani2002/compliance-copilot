# Market research — Senior AI Engineer (Germany), 2026-08-23

**Method.** 3 researcher agents opened the full text of **50 unique, currently-open ads** (≤60 days) across Indeed (15), StepStone (5), LinkedIn/company career pages (15), aggregators arbeitnow/join/aijobs (15). Cities: Berlin, Munich, Hamburg, Frankfurt, Stuttgart, Cologne. Only tools **explicitly named** in an ad were tagged. Raw blocks with URLs and verbatim snippets: `docs/research/raw/*.md`. Rejected: ads >60 days, closed (HTTP 410), or not GenAI/LLM (classic recsys/perception). Caveats: sample skews to English-indexed ads; Xing yielded nothing usable; Firecrawl rate-limited so WebFetch was used.

## What the numbers say (planner read)

1. **Agents + RAG are the job (58% each).** Not "LLM fine-tuning" (20%). Ads ask for "agentic workflows… beyond simple chains or demos, ideally in production", "state management, tool-calling, and memory systems", "LangGraph, CrewAI oder vergleichbare Orchestrierungswerkzeuge".
2. **Evaluation is the differentiator (32% generic, specific tools <5%).** "Evals & Qualität: Eval-Pipelines, damit KI-Outputs messbar zuverlässig sind", "Du sorgst für Evals, Monitoring, Kostenkontrolle", "evaluierst und benchmarkst AI- und Agentensysteme". Few ads name Ragas/DeepEval/LangSmith → the *practice* matters, tool choice is yours to justify.
3. **MCP is already mainstream (20%)** — named explicitly by N26, Infosys, commercetools, Ecoza, Anthropic, Bluefish. Multi-agent 30%.
4. **Guardrails/safety appear explicitly in ~10% but with senior framing**: "Prompt injection mitigation", "Governance, Guardrails, Datenschutz (DSGVO) und … AI-Act", "secure handling of auth and data". GDPR/EU shows up in the German-language ads.
5. **Infra is table stakes**: AWS 50%, Azure 40%, K8s 38%, Docker 34%, CI/CD 32%, Terraform 18%, FastAPI 14%, observability/tracing 16% (Langfuse/LangSmith named).
6. **German C1 is a hard filter in 46%** — not a project concern, but pick a German/EU-flavoured domain so the project itself signals market fit.
7. **LangChain 28% / LangGraph 22% / LlamaIndex 14%** — LangGraph is the named agent framework most often; LangChain is named as the ecosystem.

**Jay's gap vs. this list:** already has RAG + pgvector + Claude + tests (Agora). Missing public proof of: LangGraph multi-agent with durable state, eval pipelines gating releases, guardrails/prompt-injection defense, MCP, tracing/observability, Docker/CI/cloud deploy, ADR-level system-design writing.

## Top 3 project options (ranked)

### ⭐ 1. "Compliance Copilot" — agentic RAG over EU AI Act + GDPR with an eval-gated release pipeline
**What it is.** A LangGraph multi-agent system (router → retriever → answerer → critic/verifier) answering questions about the EU AI Act and GDPR from the official EUR-Lex texts, with citations. Tools exposed through an **MCP server** (search, fetch-article, cite). **Guardrails**: prompt-injection detection, PII redaction, refusal policy, output schema validation. **Evals as a first-class system**: golden Q&A set + Ragas faithfulness/answer-relevancy + LLM-as-judge + trajectory checks (did the agent call the right tools?), run in **GitHub Actions and blocking merge** if scores regress. **Observability**: Langfuse (self-hosted, EU) tracing + cost dashboard. FastAPI + streaming, Postgres + pgvector, Docker Compose, deployed in the EU (Hetzner/Railway EU), Terraform stub for AWS.
**What it proves.** Production agent design, eval discipline, security thinking, EU/GDPR awareness — exactly observations 1–5.
**Tools you'll learn.** LangGraph (StateGraph, checkpointers, interrupts, subgraphs), LangChain core, MCP (Python SDK), Ragas/DeepEval + LLM-as-judge, Langfuse, Guardrails patterns, FastAPI, pgvector, Docker, GH Actions, Terraform basics.
**Ad requirements ticked.** agents, RAG, multi-agent, LangGraph, LangChain, MCP, evaluation, custom-guardrails, GDPR, observability, FastAPI, Docker, CI/CD, vector-db, pgvector, AWS(Terraform), streaming, Anthropic/OpenAI.
**LinkedIn headline.** "I built an EU AI-Act & GDPR compliance agent where every PR must pass an LLM eval suite before merge — LangGraph multi-agent, MCP tools, prompt-injection guardrails, Langfuse tracing, deployed in the EU. Here's the architecture and the numbers."
**Risk.** Scope creep (multi-agent + evals + MCP + infra). Mitigation: week 1–2 = single-agent RAG with evals gating CI; multi-agent, MCP, guardrails layered in weeks 3–5. Domain is swappable (e.g. German Arbeitsrecht, e-commerce support) without changing architecture.

### 2. "Ops Agent" — multi-agent customer-operations system with human-in-the-loop and MCP tools
**What it is.** LangGraph supervisor + specialist agents (order lookup, refund policy, shipping) acting on a mock e-commerce backend exposed as **MCP servers**; **durable state** via Postgres checkpointer; **human-in-the-loop interrupts** for refunds over a threshold; trajectory evals (tool-call correctness, loop detection); guardrails on tool inputs; Langfuse tracing; FastAPI streaming API.
**Proves.** Deepest "agentic" credibility (state, memory, tool-use, HITL) — the N26/Delivery Hero/commercetools flavour.
**Learn.** LangGraph advanced (interrupt/Command, checkpointers, subgraphs, Send), MCP servers + client, trajectory evals, idempotent tool design, HITL UX, FastAPI.
**Ticks.** agents, multi-agent, LangGraph, MCP, evaluation, streaming, FastAPI, Docker, CI/CD, observability, custom-guardrails.
**Headline.** "A multi-agent support system that pauses for a human before it refunds money — LangGraph + MCP + trajectory evals."
**Risk.** Less RAG; mock backend can look toy-like unless the eval + HITL story is very strong. Weaker GDPR/EU signal.

### 3. "LLM Gateway" — model-agnostic guardrail + eval + routing gateway (LLMOps)
**What it is.** FastAPI gateway in front of OpenAI/Anthropic/Bedrock: prompt versioning, cost-tiered routing with fallback, guardrails (injection, PII, topic), rate limiting, Langfuse tracing, promptfoo/DeepEval regression suite in CI, Helm chart + Terraform for AWS/K8s.
**Proves.** Platform/LLMOps maturity — the SAP/Siemens/Capgemini/consultancy flavour (Kubernetes 38%, Terraform 18%, MLOps 24%).
**Learn.** Guardrails in depth, eval harnesses, multi-provider SDKs, K8s/Helm/Terraform, observability, cost control.
**Ticks.** MLOps, observability, evaluation, custom-guardrails, Kubernetes, Terraform, AWS, Docker, CI/CD, FastAPI, OpenAI/Anthropic/Bedrock.
**Headline.** "I built the LLM gateway I wish every team had: guardrails, evals in CI, cost routing, tracing — K8s-deployed."
**Risk.** Little LangGraph/agents (the #1 and #2 asks at 58%). Infra-heavy; recruiters for "AI Engineer" may read it as DevOps.

## Recommendation
