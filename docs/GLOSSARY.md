# Glossary (shared naming — all agents use these terms)

- **ad** — one job posting, identified by its URL.
- **requirement** — a tool/concept explicitly named in an ad (e.g. "LangGraph"), not inferred.
- **raw file** — `docs/research/raw/<source>.md`: one block per ad: URL, company, city, title, date seen, verbatim requirement snippets.
- **tally** — `docs/research/market_research.md`: requirement → count → % of ads → 2-3 example URLs.
- **project option** — one of the 3 candidate portfolio projects proposed at end of Phase 0.
